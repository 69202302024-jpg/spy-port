วิธีลงเว็บไซต์บน GitHub Pages

ทำฟรีได้ภายใน 3 นาที

  1. สมัครสมาชิก GitHub แล้วสร้าง Repository ใหม่ ตั้งชื่อว่า my-academic-portfolio
  2. อัปโหลดไฟล์ นำโค้ดนี้เซฟเป็นไฟล์ index.html แล้วอัปโหลดเข้า Repository
  3. เปิดตั้งค่า Pages ไปที่เมนู Settings > Pages
  4. เลือก Branch ตรง Source เลือก main หรือ master และเลือกโฟลเดอร์ / (root) กด Save
  5. เสร็จสิ้น! รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้ เช่น https://yourusername.github.io/my-academic-portfolio
